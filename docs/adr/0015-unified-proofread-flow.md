# ADR 0015：统一校对流程 —— 预处理 → todolist → 三阶段主校对

**状态**：提议中
**日期**：2026-07-03
**决策者**：MikeTheWiTness
**关联**：[[ADR 0008 语文节点图]](0008-chinese-node-graph-proofreading.md)、[[ADR 0009 语文知识维度叠加]](0009-chinese-knowledge-dimension-overlay.md)、[[ADR 0006 物理 ReAct]](0006-physics-react-subject-specialization.md)、[[ADR 0014 化学知识 prompt]](0014-chemistry-knowledge-react-prompt.md)

---

## 背景

ADR-0008（语文节点图）和 ADR-0009（语文知识维度叠加）分别解决了题目校对和知识校对，但它们是两套独立流程。ADR-0014 为化学增加了 `knowledge_agent_prompt_lines`，进一步加剧了拆分。

实际场景中，讲义拆分出的单元经常**混合知识讲解和配套题目**——二分类判定不足以处理。同时物理、化学等理科也需要同类能力。

**本 ADR 将题/知识/混合三种场景统一为一个三段式校对流程，全学科共用。**

---

## 决策

### 决策 1：统一流程 = 预处理 → 形成 todolist → 三阶段主校对

```
┌─ 预处理阶段 ──────────────────────────────────────────┐
│                                                        │
│  ① 内容类型判定（题 / 知识 / 混合）                      │
│     各科在 agent_prompt 中自定判据，不依赖程序预分类       │
│                                                        │
│  ② 前置准备（按需，各科自定）                             │
│     语文：前置参考检索（文言文/古诗原文比对）               │
│     物理/化学/历史/英语/数学：无前置检索，跳过              │
│                                                        │
│  ③ 展开 todolist                                       │
│     纯题目 → 通用维度 + 题目专项                         │
│     纯知识 → 通用维度 + 知识专项                         │
│     混合   → 通用 → 知识专项 → 题目专项 → 混合专项        │
│                                                        │
└────────────────────────────────────────────────────────┘
                          ↓
┌─ 主校对阶段 ──────────────────────────────────────────┐
│                                                        │
│  【第一阶段：通用检查】强制执行，不区分内容类型             │
│    · 标点符号规范                                       │
│    · 题号/板块号连续性与格式                             │
│    · 错词错字 + 病句                                    │
│    · 学科用语规范（语文：通假字；物理：单位/矢量；化学：方程）│
│                                                        │
│  【第二阶段：类型专项】根据第 0 步结果选择                 │
│                                                        │
│  ┌ 题目专项 ───────────────────────────────────┐       │
│  │ 题干严谨性 → 解析/答案正确性                   │       │
│  │ 物理：难题判定 → 独立解题 agent（切题干+题图）  │       │
│  │ 化学：计算验证（配平/计量工具）                 │       │
│  └──────────────────────────────────────────────┘       │
│                                                        │
│  ┌ 知识专项 ───────────────────────────────────┐       │
│  │ 概念/公式/定义的准确性                          │       │
│  │ 示例/素材的恰当性与适用方向                     │       │
│  │ 引用完整性（语文：古文原文比对；历史：史料核查）  │       │
│  └──────────────────────────────────────────────┘       │
│                                                        │
│  ┌ 混合专项（仅混合内容）──────────────────────┐       │
│  │ 知识-题目匹配度：                                 │       │
│  │   · 题目考察的知识点是否在前文讲解中出现          │       │
│  │   · 题目难度/深度与讲解详略程度是否对等           │       │
│  │   · 素材的寓意/适用角度与题目要求是否一致          │       │
│  │   · 题目答案能否从前文知识合理推导                │       │
│  │ 报告分段：### 知识部分 / ### 题目部分 / ### 匹配度 │       │
│  └──────────────────────────────────────────────┘       │
│                                                        │
│  【第三阶段：输出】                                      │
│    标记原文 + 修改原因 + 格式自检                        │
│                                                        │
└────────────────────────────────────────────────────────┘
```

### 决策 2：内容类型判定由 LLM 自主完成

各科在 agent_prompt 的预处理阶段定义自己的判据。不给程序增加预分类逻辑——LLM 的文本理解能力足以区分题/知识/混合，且 prompt 层面的判据可以随学科迭代，无需改代码。

判据示例：

| 学科 | 题 | 知识 | 混合 |
|------|-----|------|------|
| 语文 | 含选项ABCD、题干引导语、题目解析结构 | 含素材条目标记、概念定义、无题目→答案结构 | 知识讲解后附配套练习题 |
| 物理 | 含"已知/求/解"结构，选择题选项为数值/公式 | 以定义段+公式块为主，无"答案"段落 | 公式讲解后跟例题 |
| 化学 | 含化学方程式 + "求某物质质量"等计算要求 | 实验步骤描述、反应现象归纳、配平规则 | 反应讲解后跟练习 |
| 历史 | 含"根据材料……""结合所学……"等设问 | 年代/事件/原因/影响的知识归纳 | 史料分析后跟思考题 |

### 决策 3：合并拆分模式，统一 prompt

**拆分侧**：删除 `knowledge_smart` 和 `knowledge_manual`。统一使用 `smart` / `manual` / `rule` / `none` 四种分割方式，不再区分知识和题目的拆分逻辑。

**提示词侧**：
- 各科 `agent_prompt.json` 统一为"预处理→todolist→三阶段主校对"结构
- `get_knowledge_prompt()` 不再独立提供知识 prompt——合并入 agent_prompt，ReAct 模式统一用 agent_prompt，非 ReAct 模式保持 question_prompt_lines / knowledge_prompt_lines 分别用于题目和知识
- 化学的 `knowledge_agent_prompt_lines`（ADR-0014）废弃，知识校对逻辑合并入统一 agent_prompt

### 决策 4：各科差异化仅体现在专项维度

通用阶段（标点/错词/学科用语）全学科统一。差异仅存在于第二阶段的类型专项：

| 学科 | 题目专项独有 | 知识专项独有 |
|------|------------|------------|
| 语文 | 文本类型→节点分支 | 素材适用性、引用原文比对 |
| 物理 | 难题→独立解题 agent | 公式正确性、单位一致性 |
| 化学 | 方程验证、化学计量 | 配平规则、反应条件 |
| 历史 | 史料分析、设问逻辑 | 年代准确性、因果链条 |
| 英语 | 语法正确性、选项逻辑 | 语法规则描述、用法示例 |
| 数学 | 计算正确性、证明逻辑 | 定义严谨性、定理条件 |

---

## 影响

- **正面**：题/知识/混合统一入口，减少 prompt 碎片化。拆分逻辑简化（删除 2 个模式）。LLM 自主判定比程序预分类更灵活。
- **风险**：混合内容的"知识-题目匹配度"是新增维度，需要实际数据验证判断质量。
- **废弃**：化学 `knowledge_agent_prompt_lines` 将被合并，需确认无回归。
- **兼容性**：非 ReAct 模式的 question_prompt_lines / knowledge_prompt_lines 保持不变。

## 实现计划

| 步骤 | 文件 | 内容 |
|------|------|------|
| 1 | `agent_prompt.json`（全科） | 重写为"预处理→todolist→三阶段主校对" |
| 2 | 下拉分割方式 | 删除"知识智能分割""知识人工标记" |
| 3 | 各科 `subject.py` | `split_lecture` 去掉 knowledge_split 分支 |
| 4 | 各科 `get_knowledge_prompt()` | ReAct 模式统一返回 agent_prompt（不再有独立 knowledge_agent） |
| 5 | 化学 `config.json` | 标记 `knowledge_agent_prompt_lines` 为废弃（保留以备回退） |
| 6 | 物理 agent_prompt | 独立解题 agent 从"第 6 步固定执行"改为"题目专项中按需触发" |

### 分科优先级

| 优先级 | 学科 | 理由 |
|--------|------|------|
| P0 | 语文 | 已有节点图+维度叠加，改动最小，验证方案 |
| P1 | 物理 | 独立解题接口已预留，验证"混合+难题判定" |
| P1 | 化学 | 已有 knowledge_agent_prompt，验证合并效果 |
| P2 | 历史 | 新学科，直接使用新架构 |
| P2 | 英语/数学 | 内容类型相对简单，改动少 |
