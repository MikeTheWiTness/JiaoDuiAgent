# Issue 031：英语 agent_prompt 重写

## Parent

ADR-0015（统一校对流程）— P2 英语

## What to build

将初中英语 `agent_prompt.json` 重写为"预处理→todolist→三阶段主校对"架构。

**英语特有维度**：
- 内容类型判据：选择题选项（A/B/C/D）+ 语法改错题型 → 题；语法规则讲解、词汇表 → 知识
- 通用检查：标点、拼写、大小写、基本语法
- 题目专项：选项逻辑、答案正确性、语法改错准确度
- 知识专项：语法规则描述准确性、词汇用法示例恰当性
- 英语通常无混合内容（讲义即知识，试卷即题目），但保留混合入口

## Acceptance criteria

- [ ] agent_prompt 为三段式结构
- [ ] 题目和知识两种类型正确区分
- [ ] 非 ReAct 模式不受影响
