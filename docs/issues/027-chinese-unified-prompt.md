# Issue 027：语文 agent_prompt 重写为"预处理→todolist→三阶段主校对"

## Parent

ADR-0015（统一校对流程）— P0 语文

## What to build

将高中语文 `agent_prompt.json` 从当前的"第 0 步判定 + 第一部分题目节点图 + 第二部分知识维度叠加"结构，重写为统一的"预处理 → todolist → 三阶段主校对"架构。

**新结构**：
- **预处理**：内容类型判定（题/知识/混合，语文判据保留不变）+ 前置参考检索（文言文，保留不变）
- **形成 todolist**：plan_update 声明对应的检查维度列表
- **第一阶段（通用）**：标点、题号、错词错字、病句、学科用语
- **第二阶段（类型专项）**：
  - 题目 → 文本类型判定 → 8 分支节点图
  - 知识 → 维度叠加（准确性/素材适用性/引用完整性）
  - 混合 → 知识专项 → 题目专项 → 知识-题目匹配度
- **第三阶段（输出）**：标记原文 + 修改原因 + 格式自检

语文已有完整的节点图和维度叠加体系，改动主要是**重组结构而非重写内容**。混合内容的匹配度维度需要新增。

## Acceptance criteria

- [ ] agent_prompt.json 结构符合"预处理→todolist→三阶段"三段式
- [ ] 纯题目内容：LLM 判定为"题"，走节点图分支
- [ ] 纯知识内容：LLM 判定为"知识"，走维度叠加
- [ ] 混合内容（素材+配套题）：LLM 判定为"混合"，报告中出现 ### 知识部分 / ### 题目部分 / ### 匹配度评估
- [ ] 文言文前置检索不受影响
- [ ] 非 ReAct 模式回退到 question_prompt_lines / knowledge_prompt_lines 不变
