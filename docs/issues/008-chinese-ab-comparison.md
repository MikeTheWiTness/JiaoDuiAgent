# 008: 高中语文节点图 AB 对比验证

## Parent

ADR-0008（语文校对节点图重构）

## What to build

从现有拆题结果中选取覆盖 8 个分支的代表性题目，分别用旧 prompt 和新 prompt 跑校对，产出对比报告。

- 每分支至少选取 1 题（共 ≥8 题），优先选取已有校对记录的历史题目（可对比新旧结果）。
- 对比维度：
  - **机械错误检出率**：标点、错别字、题号编号是否正确检出
  - **内容质量判断**：答案/解析的校对是否合理（正确判断为正确、错误被标记）
  - **格式合规率**：标记数 = 原因数比率、标记格式正确率
  - **轮次消耗**：新旧方案的 tool_calls 轮次对比
  - **分支路由正确性**：LLM 是否走到了正确的分支（对文言文是否避免了错别字扫描）
- 输出对比报告（Markdown），含每题的对比结果和总体结论。
- 若有分支效果不如旧 prompt，记录具体差异，决定是否需要调整该分支的 todolist。

## Acceptance criteria

- [ ] 8 个分支各至少 1 题完成 AB 对比
- [ ] 对比报告含 5 个维度的新旧对比数据
- [ ] 文言文分支验证：确认 LLM 没有做错别字扫描
- [ ] 所有分支的格式合规率 ≥ 旧 prompt
- [ ] 机械错误检出率不低于旧 prompt
- [ ] 对比报告批准后，Issue 009 可开始
