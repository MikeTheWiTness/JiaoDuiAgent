# 007: 重写高中语文 agent_prompt.json — 8 分支节点图

## Parent

ADR-0008（语文校对节点图重构）

## What to build

将 `subjects/高中语文v3.0/agent_prompt.json` 从当前 79 行的纯 LLM 自主规划 prompt 替换为节点图 prompt。核心变化：

- **第 0 步：文本类型识别**。LLM 根据题干特征自判类型（8 种：论述类文本、文学类文本、实用类文本、文言文、古诗词、名句默写、语言文字运用、写作题），prompt 写明每种类型的区分判据。
- **8 条分支各有独立的固定 todolist**。机械检查（标点、错字、题号编号、格式）在前，"主内容校对"（答案逻辑/翻译准确性/鉴赏合理性/得分点设置）在后，最后两步固定为格式自检 + 输出校对报告。
- **文言文/古诗词分支不做常规错别字识别**——仅做前置参考逐字比对。
- **分支切换两阶段确认协议**：①声明怀疑理由 → ②重新审视原文特征 → ③确认后切换分支。
- **格式自检步骤**：bash 能修的直接修（编号格式/段落缺失/标记格式），修不了的（标记与原因实质不匹配）打回重做。
- **`plan_update` 用法**：第 1 轮声明对应分支的 todolist，后续逐步标记 completed。不做自主规划。
- **反思范围仅格式自检**，不做内容层打回。
- 标记格式规则复用现有规则，不做改动。

## Acceptance criteria

- [ ] 新 prompt 包含 8 条分支，每条分支的 todolist 完整且步骤顺序固定
- [ ] 文本类型识别判据明确（文言文 vs 现代文、诗歌 vs 散文、论述类 vs 实用类等关键区分点）
- [ ] 文言文/古诗词分支明确禁止常规错别字识别
- [ ] 分支切换协议写入了两阶段确认流程
- [ ] 格式自检步骤写入每条分支（倒数第二步）
- [ ] `plan_update` 使用说明从"首轮自主声明计划"改为"声明对应分支 todolist + 逐步标记"
- [ ] 旧 prompt 备份为 `agent_prompt_v3.0_backup.json`（本 issue 做备份，Issue 009 做最终切换）
- [ ] 非 ReAct 模式不受影响（`question_prompt_lines` 不动）
