# Issue 028：物理 agent_prompt 重写 + 独立解题按需触发

## Parent

ADR-0015（统一校对流程）— P1 物理

## What to build

将高中物理 `agent_prompt.json` 从当前的固定 9 步工作流，重写为"预处理→todolist→三阶段主校对"架构。

**关键差异（区别于语文）**：
- 内容类型判据：物理特有——"已知/求/解"结构、选择题数值选项、定义段+公式块
- 知识专项维度：公式正确性、单位一致性、物理定律表述
- 题目专项：**难题判定 → 独立解题 agent** 不再是固定第 6 步，改为"题目专项中按需触发"——LLM 判定为难题时才调用 independent_solve，切下题干+题图发送
- 无前置检索（物理没有古籍/原文比对需求）
- 通用检查中的学科用语：单位符号、矢量符号、公式排版

## Acceptance criteria

- [ ] agent_prompt 结构为三段式
- [ ] 纯题目：LLM 正确识别，难题时触发 independent_solve
- [ ] 纯知识：LLM 正确识别，走公式/单位/定律维度
- [ ] 混合内容（公式讲解+例题）：走通用→知识→题目→匹配度
- [ ] 独立解题 agent 仅在题目专项中、且 LLM 判定为难题时触发
- [ ] sympy 工具不受影响
