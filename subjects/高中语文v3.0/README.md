# 高中语文校对工具 v3.0

AI 驱动的高中语文题目校对工具 —— Word 转 Markdown → 智能拆分 → ReAct 代理校对 → 校对报告生成。**ReAct 模式范例学科。**

## v3.0 核心：ReAct 代理模式

作为 v3.0 的 ReAct 范例实现，高中语文展示了 LLM 如何**自主规划、定位原文、验证证据、标注错误**：

| 能力 | 工具 | 说明 |
|------|------|------|
| 计划管理 | `plan_update` | 声明步骤 → 逐项执行 → 自检输出 |
| 文本定位 | `locate_paragraph` / `read_section` | 在长篇文言文/现代文中精确搜索和按范围读取 |
| 前置参考 | 识典古籍 / 搜韵网 | 文言文原文自动检索 + diff 比对（校对前注入） |

ReAct 模式通过 GUI 开关一键切换，关闭时回退到传统一次性校对模式。

## 功能特点

- **格式转换**：Word `.docx` → Markdown（Pandoc，保留下划线、波浪线等格式标记）
- **智能拆分**：支持普通规则 / 不拆分 / 智能分割 / 人工标记 四种拆分方式
- **文言文 & 诗歌校对**：自动识别文本类型 → 识典古籍 + 搜韵网检索 → 逐字 diff 比对
- **批注评审**：提取 Word 批注 → 逐条评审批注质量（正确/错误/需补充） → 补充遗漏错误
- **自由校对**：直接粘贴文本或上传文件，无需 Word 格式
- **PDF 报告**：LaTeX 双栏对照排版（左栏原题 + 圈号标记，右栏修改建议）

## 快速开始

```bash
cd JiaoDuiAgent
pip install -r requirements.txt
python subjects/高中语文v3.0/main.py
```

## 工具说明

| 工具 | 类型 | 说明 |
|------|------|------|
| `plan_update` | ReAct | 校对计划管理（声明/更新/完成） |
| `locate_paragraph` | ReAct | 关键词搜索定位原文段落 |
| `read_section` | ReAct | 按行号范围读取原文 |

前置参考搜索（识典古籍 / 搜韵网）在 `pre_proofread_hook` 中自动运行，不在 LLM 工具列表中。

## 校对范围

1. 文字校对：错别字、漏字、多字、标点符号误用
2. 图片校对：图片缺失、配图与题目一致性
3. 文言文：通假字标注、实词虚词释义、断句标点、典故出处
4. 现代文阅读：文本引用准确性、题干表述清晰度
5. 诗歌鉴赏：诗句引用完整性、意象分析合理性
6. 语言文字运用：成语使用、病句辨析、修辞手法判断
7. 写作题：材料理解、立意引导
8. 答案校验：答案与题干匹配、解析逻辑自洽、得分点合理

## 数据流

```
.docx 文件
  → Pandoc → 原始 .md（保留格式标记: <批注> <下划线> <波浪线>）
  → 拆分 → 第N题/第N题.md + 第N题_clean.md + images/
  → 前置处理: 文言文识别 → 识典古籍/搜韵网搜索 → 节选 → diff → 注入「前置参考」
  → ReAct AI 校对（plan → locate → verify → mark）
  → _校对报告.md + _校对数据.json + _API对话记录.md
  → LaTeX PDF（可选）
```
