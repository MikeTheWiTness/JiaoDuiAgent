# 0002-智能分割采用XML标记方案

智能分割功能中，LLM 的输出格式选择 XML 标记方案（在原文中插入 `<problem></problem>` 标签），而非 JSON 方案。

## 背景

智能分割需要 LLM 将文档按"完整题目单元"拆分。有两种候选方案：
1. **JSON 方案**：LLM 返回 JSON 数组，每个元素包含 title 和 content
2. **XML 标记方案**：LLM 在原文中插入 `<problem></problem>` 标签标记边界

## 决策

选择 XML 标记方案。理由：

1. **内容准确性**：原文一字不动，只插标签，避免 LLM 重写全文时漏字、改字
2. **Token 效率**：只需插入少量标签，不重复输出全文
3. **格式容错**：标签简单，出错概率低于 JSON（转义引号、嵌套等问题）
4. **支持丢弃内容**：未被标记的内容即为应丢弃的引言/过渡文字
5. **人工可审核**：直接看原文就能检查标记是否正确
6. **降级方便**：识别失败时降级为"全文作为一个单元"，不会丢内容

失败时重试一次，再次失败则降级为不拆分。

## 后果

- 需要实现 XML 标签解析逻辑（正则提取 `<problem>` 之间的内容）
- 提示词需要强调"绝对不修改原文任何一个字"
- 预留了未来扩展空间（需要时可加 `type` 属性区分题型）
