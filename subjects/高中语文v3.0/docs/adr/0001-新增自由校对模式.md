# 0001-新增自由校对模式

在现有讲义/试卷两种模式之外，新增"自由校对"模式，作为第三种 source mode。

## 背景

高中语文校对需求灵活多样：有时需要校对一段文字、一首诗，有时是一篇文言文带几道小题，有时是一整份试卷。现有的讲义模式和试卷模式都假设输入是结构化的文件（有固定的标题/题号格式），无法满足灵活的校对需求。

## 决策

新增"自由校对"模式，与讲义模式、试卷模式并列。

- 支持粘贴文本 + 上传图片，也支持上传 Word/MD 文件
- 粘贴内容临时存为 md + images 文件夹，复用现有转换/拆分/校对/报告生成流程
- 拆分方式三选一：不拆分、普通规则拆分、智能分割（LLM 识别）
- 输出目录名为 `自由校对_时间戳`
- 同样生成详细 PDF 校对报告，走"重工具"路线，与轻量的网页版 Chat 形成差异化

## 后果

- 复用现有 DefaultApp 模板，通过 `_get_ui_features` 扩展，不单独做 GUI
- 模式切换时 UI 动态变化（隐藏讲义/试卷特有选项，显示文本输入框等）
- 维护成本可控，一套代码支持三种模式
