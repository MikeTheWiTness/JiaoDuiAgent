# 0006-人工标记分割使用成对标记

人工标记分割使用 `###### 题目开始 ######` 和 `###### 题目结束 ######` 成对标记，而非单行分割线。

## 背景

文档来源混乱时，需要允许用户预先在 Word 或 MD 文件中手动标记题目边界，程序按标记直接切分。

候选方案：
1. 单行分割线（如 `###### 题目分割线 ######`）
2. 成对开始/结束标记

## 决策

选择成对标记方案：`###### 题目开始 ######` / `###### 题目结束 ######`。

理由：
1. 边界清晰，不易混淆
2. 自然支持跳过开头的引言、说明、过渡文字（未被标记的内容自动丢弃）
3. 人工操作时不容易漏（漏了结束标记程序可以检测并报错）
4. 符合 Markdown 语法（六级标题），在编辑器中有高亮显示
5. 程序识别简单可靠

如果文件中未找到有效标记（开始结束不配对或数量为0），报错提示用户，不自动降级。

## 后果

- 需要实现成对标记的解析和校验逻辑
- 需要检测不配对的标记并给出友好的错误提示
- 全模式可用（讲义、试卷、自由校对、批注评审）
