# 0007-版本从v1.1直接升级到v2.0

高中语文校对工具从 v1.1 直接升级到 v2.0，在原目录上迭代。

## 背景

v1.1 版本存在接口不兼容等问题，且本次更新新增了大量功能：
- 自由校对模式
- 智能分割（LLM 识别 + XML 标记）
- 人工标记分割
- 批注评审模式
- 文言文/诗歌前置原文搜索 + 自动差异比对 + LLM 判断的三层架构
- 识典古籍适配

这是一次重大版本升级，功能和架构变化远超小版本迭代。

## 决策

- 在 v1.1 目录上直接修改，不新建目录
- 版本号从 v1.1 直接跳到 v2.0
- 理由：v1.1 本身存在接口不兼容问题，实际使用价值有限，无需保留

## 后果

- 无需维护多版本代码
- 用户直接感受到功能的巨大提升
- 后续小版本迭代用 v2.1、v2.2 等
