# 0004-复用现有GUI模板，不独立做界面

高中语文 v2.0 不单独开发 GUI 界面，在现有 DefaultApp 模板上扩展。

## 背景

新增自由校对模式、智能分割等功能后，是否需要独立一套 GUI 界面存在疑问。独立界面可以更灵活，但维护成本高，且与现有流程割裂。

## 决策

在现有 `DefaultApp` 模板上扩展，通过学科自定义的 `_get_ui_features` 机制控制功能开关和显示。

具体扩展点：
1. source_mode 增加"自由校对"选项（与"讲义""试卷"并列）
2. 转换设置区增加"智能分割"复选框（默认关闭，全模式可用）
3. 自由校对模式下显示文本输入框和图片上传按钮，隐藏讲义/试卷特有选项
4. 复用现有文件添加、列表、日志、报告导出等通用功能

## 后果

- 维护成本低，一套 UI 框架支持所有学科
- 自由校对模式通过动态显隐控件实现，无需重写界面
- 学科间 UI 行为一致，用户学习成本低
- 如未来需要高度定制化的界面，可再考虑独立
