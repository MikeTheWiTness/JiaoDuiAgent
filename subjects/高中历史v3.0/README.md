# 高中历史校对 v3.0

高中历史学科的校对工具，支持中国古代政治制度、变法改革等专题的智能校对。

## 语言

**校对单元**：
- 最小校对单元为一道例题（例1、例2……）或一道练习题
- 知识板块以模块和知识子板块为自然边界进行切割
- 不做复杂的素材条目切割（与语文不同）

## 校对流程

### 题目校对
采用「历史题目节点图」分 3 条分支：
1. **选择题**：题干+选项逻辑+答案校验+解析自洽
2. **材料解析题**：材料引用+设问匹配+答案质量
3. **综合题**：以上两者的组合

### 知识校对
采用「维度叠加」架构，维度仓库包括：
- **① 语言规范层**：结构格式 / 标点符号 / 错别字 / 病句（始终启用）
- **② 史实准确性**：年代/人名/制度名/因果关系/地理信息
- **③ 概念定义准确性**：历史概念的准确定义
- **④ 表格数据一致性**：表格内数据自洽检查
- **⑤ 逻辑自洽性**：因果推理和前后一致性
- **⑥ 嵌入题目**：知识板块中嵌入的题目走题目节点图

## 与其他学科的区别

| 维度 | 高中语文 | 高中历史 |
|------|----------|----------|
| 最小校对单元 | 一道小题（复杂切割） | 一道例题（简单切割） |
| 知识组织 | (N) 素材条目 + 固定段头 | 表格 + 文本段落 + 标题层级 |
| 前置检索 | 文言文→识典古籍 | 不需要 |
| 工具需求 | plan_update + read_section | plan_update + read_section |
