# 0008-批注评审PDF采用逐条展开式排版

批注评审模式的 PDF 报告采用逐条展开式排版。

## 背景

批注评审模式的 PDF 需要同时展示原文、原批注、评判结果、补充发现等多种信息。有三种候选方案：
1. 三栏式（原文+原批注+评判，横向三栏）
2. 上下式（上原文，下双栏）
3. 逐条展开式（原文完整展示 → 逐条评判 → 补充发现）

## 决策

选择方案 C：逐条展开式。

排版结构：
1. 原文完整展示（带批注位置标记，圈号①②③）
2. 批注评审区：按编号逐条展开
   - 原批注内容
   - 评判结果（✅正确 / ❌有误 / ⚠️部分正确）
   - 评判理由
3. 补充发现区（原批注未提及的问题，按正常校对标记格式）

理由：
1. 逻辑清晰，符合"先看原文，再逐条评判"的阅读习惯
2. 实现相对简单，不需要复杂的多栏布局
3. 原文阅读空间大
4. 后续可根据实际使用效果调整

## 后果

- 需要新增批注评审专用的 LaTeX 生成函数
- 与现有的 paracol 双栏模板并行（普通校对对用双栏，批注评审用逐条展开）
- 如后续效果不满意，可再迭代排版方式
