# 0005-新增批注评审模式

新增"批注评审"作为第四种 source mode，专门处理带有人工批注的 Word 文档。

## 背景

实际工作中存在这样的场景：实习生或初级校对员已经在 Word 中用批注功能写了初步的校对意见，需要资深教研员（或 LLM）来：
1. 评判已有批注的正确性（对/错/部分对）
2. 补充发现遗漏的错误

这与普通校对不同——输入包含人工批注，输出需要包含对批注的评审。

## 决策

新增"批注评审"模式，作为第四种 source mode（与讲义、试卷、自由校对并列）。

- 输入：带批注的 Word 文档（.docx）
- 转换时提取批注内容，用 `[📝批注：xxx]` 形式插入到原文对应位置
- 输出格式：专门的批注评审格式（原文 + 逐条评审 + 补充发现）
- 同样生成详细 PDF 报告
- 支持所有分割方式（不拆分、普通规则、智能分割、人工标记）

## 后果

- 需要实现 Word 批注提取功能
- 需要新增批注评审专用的提示词
- PDF 生成需要新增批注评审排版模板
- LLM 需要同时做"评判他人意见"和"自己校对"两件事
